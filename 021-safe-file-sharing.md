# Safe File Sharing

## Purpose

Safe file sharing uses minimum permissions, clear recipients, and expiration when possible.

This note is part of a public Digital Safety and Privacy Toolkit. The goal is to create practical notes that help people protect accounts, devices, files, wallets, and personal information.

## Why It Matters

Most security problems start with small repeated mistakes: weak passwords, unsafe links, old permissions, missing backups, careless file sharing, or rushed decisions. A simple checklist can prevent many of these problems.

## Practical Workflow

1. Identify what account, device, file, or action needs protection.
2. Check the main risks connected to it.
3. Apply the simplest useful protection first.
4. Save recovery information in a safe place.
5. Review permissions and settings regularly.
6. Update the process when tools, accounts, or risks change.

## Checklist

- Use strong and unique passwords.
- Turn on two-factor authentication when available.
- Avoid unknown links and suspicious downloads.
- Keep devices and apps updated.
- Back up important data before problems happen.
- Limit permissions to only what is necessary.
- Review old accounts and old access regularly.
- Keep sensitive information out of public repositories.

## Example Use

Use this note when working on safe file sharing workflow. It can be used as a checklist, reminder, or starting point for a stronger personal security process.

## Common Mistakes

- Acting quickly because of urgency or pressure.
- Trusting a link only because it looks familiar.
- Reusing passwords across important accounts.
- Ignoring old permissions and unused accounts.
- Saving sensitive information in unsafe places.
- Forgetting to test recovery before an emergency.

## Final Note

Digital safety is not about fear. It is about building calm habits that reduce risk before something goes wrong.
