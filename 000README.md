# Digital Safety and Privacy Toolkit

This repository is a public collection of practical notes about digital safety, privacy, account protection, scam prevention, wallet safety, backups, device security, and secure online habits.

## Main Areas

- Account security
- Password and two-factor authentication
- Device and browser safety
- File and document privacy
- Scam and phishing awareness
- Crypto wallet safety
- Backup and recovery planning
- Personal privacy reviews
- Small business and freelancer security

## How to Use

Each note can be read alone as a small checklist. The full collection can also work as a personal security handbook.

Security is strongest when simple habits are repeated consistently.
